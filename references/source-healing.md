# 원어 힐링: 발언 보존과 교정 검증

힐링은 녹취의 읽기를 방해하는 오류를 고치는 작업이다. 강연을 논문으로 재작성하거나, 강연자의 주장을 학술적으로 옳게 만드는 작업이 아니다. 번역 전에 이 지침으로 원본과 교정본을 대조한다.

## 1. 근거와 교정 범위

- 원본 자막·녹취를 보존한다. 교정본은 작업용 파생본이며 원본을 대신하는 증거가 아니다. 음성을 확인했다면 해당 시간 위치와 확인한 내용을 기록한다.
- 구두점, 대소문자, 명백한 행 분절은 의미를 유지하며 정리한다. 자막 표시 방식 때문에 겹친 구간만 중복 제거하고, 화자의 강조·자기 정정·반복 논증은 남긴다.
- 사전과 외부 문헌은 용어의 후보·표기를 확인하는 자료다. 그 표현을 화자가 실제 발언했다는 증거로 삼지 않는다. 문맥만으로 부정어·인명·술어를 확정하기 어렵다면 음성을 확인하거나 후보와 미확인 상태를 남긴다.
- 화자의 사실 오류로 의심되는 내용은 발언 그대로 보존하고 별도 편집자 주에 검증 결과를 적는다. 교리적 통념이나 알려진 일화를 근거로 발언을 대체하지 않는다.
- 누락된 문장·전제·반론을 만들어 완성하지 않는다. 구문을 확정할 수 없다면 `[원문 불명확: …]`로 표시하고 가능한 독해를 교정 기록에 남긴다.

## 2. 의미 보존 항목

원본의 각 주장에 대해 다음을 교정본과 확인한다. 문장 분할·병합은 가능하지만 아래 관계를 바꾸어서는 안 된다.

| 항목 | 확인할 내용 |
| :--- | :--- |
| 주체와 귀속 | 화자 자신의 견해, 인용한 인물의 견해, 통설, 질문을 구분한다. |
| 부정과 대조 | nicht, kein, sondern 등의 범위와 대조 대상을 보존한다. |
| 가능성과 유보 | vielleicht, könnte, müsste 및 확인이 더 필요하다는 발언을 유지한다. |
| 조건과 예외 | 허용·금지의 조건, 예외, 개인 견해와 공동체 규범을 구분한다. |
| 판단의 종류 | 결정 권한, 다수결, 실천적 효력, 내용의 참·거짓을 구분한다. |
| 논거와 관점 | 복수의 이유, 반론, 소수 의견, 상반된 해석을 각각 남긴다. |
| 서사와 표현 | 비유·농담·자기 정정이 의미를 구성하면 보존한다. 설명을 보충하면 편집자 설명으로 분리한다. |

## 3. 추적 기록

교정본에 `[¶N]`을 부여하고 원본의 타임스탬프 또는 행 범위를 연결한다. 타임스탬프가 없는 파일은 원본 파일명과 행 범위를 사용한다. 원본 각 구간이 어느 단락에 반영되었는지, 제외했다면 어떤 표시 중복·잡음인지 추적할 수 있어야 한다.

기록은 기존 품질 보고서의 원어 교정 절에 둔다. 힐링만 요청받았다면 교정본 말미에 별도 절로 두며, 번역 대상 본문과 구분한다. 모든 단락의 원본 위치를 기록하고, 의미에 영향을 주는 수정·불확실성은 다음 표에 남긴다. 단순 구두점 정리는 처리 방식만 묶어 기록할 수 있다.

| 원본 위치 / ¶ ID | 원본 표현 | 교정 표현 또는 후보 | 근거 | 상태 |
| :--- | :--- | :--- | :--- | :--- |
| 시간·행 / ¶N | 해당 표현 | 채택 표현 또는 원문 유지 | 음성 확인 위치·문맥·참조 자료 | 확인 / 미확인 |

## 4. 번역 진입과 최종 검수

1. 원본 전체와 교정본을 대조하여 구간 누락·추가와 의미 보존 항목을 검사한다. 교정자가 아닌 검수자가 가능하면 맡는다. 독립 검수가 불가능하면 그 한계를 보고한다.
2. 확인된 의미 변형은 수정한다. 자료 부족으로 해결하지 못한 부분은 원문과 후보·영향 범위를 명시한다. 미확인을 오류 0건으로 집계하지 않는다.
3. 대조 범위와 결과를 `통과 / 유보 포함 / 수정 필요`로 기록한다. 유보 포함이면 불확실성을 번역문에도 전달한다. 중심 논지의 독해가 확정되지 않았다면 해당 구간의 확정 번역을 보류하고 나머지는 진행한다.
4. 번역 검수자는 교정본뿐 아니라 원본 위치·교정 기록을 받는다. 의미에 영향을 준 교정과 유보 구간은 원본까지 돌아가 확인한다. 윤문 후에도 같은 구간의 부정·주체·조건이 유지되었는지 확인한다.
5. 단락 수와 길이 비율의 일치는 구조적 경보다. 의미 보존의 증명이 아니며 원본 대조를 대체하지 않는다.

## 5. 회귀 검토 사례

다음은 이 스킬의 사용 사례에서 발견된 변형이다. 해당 강연의 역사적·신학적 주장이 참인지를 판정하는 정답표가 아니다. 같은 변형을 다른 문맥에서도 막는 기준으로 사용한다.

- `die kommende Welt ist nicht die Welt nach dem Tod`를 사후 세계와의 동일시로 고치지 않는다. 뒤에 통상적 견해가 소개되어도 앞의 부정과 견해 주체를 유지한다.
- 인간이 해석의 결정 권한을 가진다는 설명을 ‘하나님이 틀렸다’는 명제로 바꾸지 않는다. 권한과 진위는 별개의 판단이다.
- `vielleicht persönlich eine andere Meinung hatte` 및 `man muss in den Text gucken`과 같은 발언은 개인 견해에 관한 추정과 원문 확인의 필요성을 함께 남긴다. 알려진 인물 간 논쟁으로 확정하여 재작성하지 않는다.
- 상징적 설명에 붙은 ‘수학적으로 정확한 것은 아니다’라는 제한을 삭제하지 않는다. 여러 이유나 창조 해석을 하나의 설명으로 통합하지 않는다.
